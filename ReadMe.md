## 🧠 Code Summarization with Fine-Tuned LLMs
This project explores the fine-tuning of Large Language Models (LLMs) to generate concise natural language summaries of Python code. By leveraging pretrained GPT-2 variants and synthetic summaries generated by Qwen2.5-coder, we aimed to improve code comprehension for both beginner and experienced developers.

## 🚀 Overview
Beginners often struggle to understand code, and even seasoned programmers benefit from quick, clear summaries. This project fine-tunes GPT-2 (Small and Medium) models on Python code to generate 1–2 sentence summaries using a dataset curated from The Stack. Summaries were generated using Qwen2.5-coder via Ollama.

## 🛠️ Methodology
Data Source: The Stack (BigCode Project)

Summarization: Synthetic summaries generated using Qwen2.5-coder:7b

Model: GPT-2 Small (124M) and GPT-2 Medium (355M)

Training: Fine-tuning with PyTorch using tokenized code-summary pairs

Evaluation: ROUGE-1, ROUGE-2, and ROUGE-L scores on unseen test data

## 📈 Results
Fine-tuned models showed significant improvement over the original GPT-2 models:

Model	Dataset	ROUGE-1 F1	ROUGE-2 F1	ROUGE-L F1
GPT-2 Small	Full	+107%	+359%	+89%
GPT-2 Medium	Full	+163%	+1052%	+165%
GPT-2 Small	Short	+92%	+351%	+84%
GPT-2 Medium	Short	+137%	+429%	+96%

## Usage

In order to use the files in the repository, take the applicable json file from data/dataset directory and fill that in to DATA_FILE_PATH variable in fine-tune_gpt2.json. That will allow you to fine tune gpt-2 once your environment is set up. 

The origional dataset can be found here: https://huggingface.co/datasets/bigcode/the-stack 

and the specific parquet file that can be downloaded to be preprocessed can be downloaded here: https://huggingface.co/datasets/bigcode/the-stack/blob/main/data/python/train-00000-of-00206.parquet
